# Support

## Public issue tracker

Open a GitHub issue for a reproducible product bug or feature request. Include
your Quill version (`quill --version`), OS, terminal, target/provider, and the
smallest safe reproduction. Never paste prompt contents, credentials, license
keys, private file paths, or customer information.

## Private support

Email **support@quillterminal.app** for:

- sign-in, trial, license, device, billing, cancellation, or refund questions;
- feedback containing private logs or screenshots;
- suspected security vulnerabilities;
- download verification problems.

Payments, plan changes, cancellations, and refunds are processed through the
customer's Paddle record. A cancellation stops renewal but does not itself
refund an earlier charge.

Documentation: <https://quillterminal.app/docs>
