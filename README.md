# Quill Terminal

Quill Terminal is a local Markdown prompt workspace for terminal-first AI
workflows. Compose and review structured prompts beside Claude Code, Codex,
Anthropic/OpenAI APIs, or a normal shell; save reusable Markdown briefs; and
keep prompt files, templates, and history on your machine.

## What it includes

- A real multiline editor and live Markdown preview inside the terminal.
- Embedded Claude Code and Codex CLI terminals, plus Anthropic and OpenAI API
  targets and a normal shell.
- Local Markdown files, templates, drafts, history, images, large-paste chips,
  find, undo/redo, layouts, themes, and keyboard-first navigation.
- Pipe input into a new or already-running Quill instance.
- macOS Intel/Apple Silicon, Windows x64/ARM64, and Linux x64/ARM64 builds.
- A 14-day full-product trial with no card.

Quill does not rewrite a prompt before sending it. It gives you an editing
surface to structure, inspect, and revise the same brief yourself.

## Install and verify

Use the authenticated download page for the recommended installer and exact
OS instructions: <https://quillterminal.app/download>.

Every release publishes SHA-256 checksums, a Sigstore bundle, a CycloneDX SBOM,
and native acceptance evidence. macOS and Windows builds are intentionally
unsigned during the demand-validation launch, so Gatekeeper or SmartScreen may
show a first-launch warning. The download page documents the exact approval
steps and checksum verification.
